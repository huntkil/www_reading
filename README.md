# 읽기 훈련 시스템 (Reading Training System)

과학적 근거에 기반한 읽기 속도 향상 훈련 시스템입니다. 인지과학 연구 결과를 바탕으로 속발음(subvocalization) 제어와 시각적 처리 능력을 향상시켜 효율적인 읽기 능력을 개발합니다.

## 🚀 주요 기능

### 📚 체계적인 훈련 시스템
- **모듈 훈련**: 이론부터 실습까지 단계별 학습
- **리딩 훈련**: 다양한 읽기 자료로 직접 훈련
- **진행 상황 추적**: 단계별 진행률과 성과 분석

### 🧠 과학적 근거 기반 훈련
- **속발음 제어**: 음운 병목 현상 이해 및 최적화
- **청킹(Chunking)**: 의미 단위 읽기 훈련
- **시각적 처리**: 안구 운동 최적화 및 페이서 훈련
- **적응적 속도**: 텍스트 유형별 읽기 전략

### 💡 스마트 도움말 시스템
- **맥락 기반 도움말**: 현재 단계에 맞는 구체적인 안내
- **과학적 설명**: 인지과학 연구 결과 기반 이론
- **실습 가이드**: 단계별 구체적인 훈련 방법
- **동기부여**: 학습 효과와 기대 결과 설명

### 🎨 사용자 친화적 UI
- **다크모드 지원**: 라이트/다크 모드 완전 지원
- **반응형 디자인**: 모바일/데스크톱 최적화
- **접근성**: 색상 대비 및 가독성 최적화
- **직관적 네비게이션**: 단계별 진행 상황 표시

## 🛠 기술 스택

- **Frontend**: Next.js 14, React 18, TypeScript
- **UI Framework**: ShadCN UI, Tailwind CSS
- **Icons**: Lucide React
- **Database**: Prisma (SQLite)
- **Styling**: CSS Modules, Tailwind CSS

## 🎯 훈련 모듈

### 1. 기초 속발음 제어 훈련 (초급)
- **목표**: 내면의 목소리 이해 및 효율적 관리
- **내용**: 속발음 이론, 물리적 억제 훈련, 허밍/카운팅 훈련
- **소요시간**: 15분

### 2. 시각적 처리 및 청킹 훈련 (중급)
- **목표**: 의미 단위 읽기 능력 향상
- **내용**: 청킹 이론, 2-3단어 청킹 훈련, 구문 단위 확장
- **소요시간**: 20분

### 3. 숙련된 읽기 및 스캐닝 훈련 (고급)
- **목표**: 고급 읽기 기법과 정보 검색 능력
- **내용**: 스캐닝 기법, 적응적 속도 훈련, 시각화 훈련
- **소요시간**: 25분

## 📖 읽기 자료

### 소설 (Fiction)
- **Alice in Wonderland**: 클래식 소설로 이야기 흐름 따라가기 훈련
- **난이도**: 초급~중급
- **특징**: 자연스러운 스토리텔링과 다양한 캐릭터

### 에세이 (Non-fiction)
- **일상 에세이**: 논리적 사고와 이해력 향상
- **난이도**: 초급~고급
- **특징**: 다양한 주제와 깊이 있는 내용

## 🔬 과학적 근거

### 인지과학 연구 기반
- **배들리-히치 모델**: 작업 기억의 음운 고리 이론
- **키스 레이너 연구**: 안구 운동과 인지 처리 과정
- **엘리자베스 쇼터 연구**: 독서 병목 현상 분석

### 훈련 효과
- **읽기 속도**: 분당 150-250단어 → 500-600단어 향상 가능
- **이해도**: 의미 기반 처리로 깊이 있는 이해
- **집중력**: 시각적 주의 집중으로 효율성 증대
