# 훈련 기능 상세 가이드

## 📚 개요

읽기 훈련 시스템은 과학적 근거에 기반한 체계적인 읽기 능력 향상 프로그램입니다. 인지과학 연구 결과를 바탕으로 속발음 제어, 시각적 처리, 의미 단위 읽기 등의 핵심 기술을 단계별로 훈련할 수 있습니다.

## 🎯 훈련 모듈

### 1. 기초 속발음 제어 훈련 (초급)

#### 목표
- 내면의 목소리(묵독) 현상 이해
- 비효율적인 속발음 습관 개선
- 음운 병목 현상 인식 및 최적화

#### 구성 단계
1. **속발음 이해하기** (이론)
   - 병리적 vs 정상적 속발음 구분
   - 음운 병목 현상 설명
   - 개선 목표 설정

2. **물리적 속발음 억제 훈련** (실습)
   - 껌 씹기 훈련
   - 발성 근육 점유를 통한 억제
   - 시각적 정보 집중 훈련

3. **허밍/카운팅 훈련** (실습)
   - 내면의 목소리 억제 기법
   - 일정한 리듬 유지
   - 효율적 처리 패턴 형성

#### 소요시간: 15분

### 2. 시각적 처리 및 청킹 훈련 (중급)

#### 목표
- 개별 단어에서 의미 단위 읽기로 전환
- 시각적 인식 범위 확장
- 예측적 읽기 능력 향상

#### 구성 단계
1. **청킹(Chunking) 이해하기** (이론)
   - 의미 단위 처리 원리
   - 시각적 확장 기법
   - 단계별 발전 과정

2. **2-3단어 청킹 훈련** (실습)
   - 기초 청킹 연습
   - 의미 단위 인식 훈련
   - 개별 단어 의존도 감소

#### 소요시간: 20분

### 3. 숙련된 읽기 및 스캐닝 훈련 (고급)

#### 목표
- 고급 읽기 기법 습득
- 정보 검색 능력 향상
- 적응적 읽기 전략 개발

#### 구성 단계
1. **스캐닝 기법 이해하기** (이론)
   - 키워드 중심 검색
   - 시각적 패턴 인식
   - 효율적 이동 기법

2. **스캐닝 훈련** (실습)
   - 특정 정보 빠른 찾기
   - 패턴 인식 훈련
   - 목표 지점 이동 연습

#### 소요시간: 25분

## 📖 읽기 자료

### 소설 (Fiction)
- **Alice in Wonderland**: 클래식 소설
  - **챕터 1**: Down the Rabbit-Hole (초급, 8분)
  - **챕터 2**: The Pool of Tears (초급, 10분)
  - **챕터 3**: A Caucus-Race and a Long Tale (중급, 12분)
  - **챕터 4**: The Rabbit Sends in a Little Bill (중급, 15분)

### 에세이 (Non-fiction)
- **일상 에세이**: 다양한 주제의 논리적 텍스트
  - **초급**: 간단한 일상 이야기
  - **중급**: 사회적 주제와 관점
  - **고급**: 깊이 있는 사고와 분석

## 💡 스마트 도움말 시스템

### 맥락 기반 도움말
각 훈련 단계에서 현재 상황에 맞는 구체적인 안내를 제공합니다:

#### 훈련 타입 선택 화면
- **모듈 훈련 vs 리딩 훈련** 차이점 설명
- **선택 가이드**: 초보자를 위한 추천사항
- **각 훈련 방식의 장점** 명시

#### 모듈 선택 화면
- **모듈별 아이콘**: 특성에 맞는 시각적 표현
- **개별 도움말**: 각 모듈의 상세 설명
- **선택 가이드**: 난이도별 추천 순서

#### 읽기 자료 선택 화면
- **소설 vs 에세이**: 학습 효과 차이 설명
- **난이도별 추천**: 초급자부터 시작하는 방법
- **선택 팁**: 개인 수준에 맞는 자료 선택

#### 훈련 세션 화면
- **단계별 도움말**: 현재 단계에 맞는 학습 팁
- **실시간 가이드**: 훈련 진행에 따른 동적 안내
- **과학적 근거**: 연구 결과 기반 설명

### 과학적 설명
모든 도움말은 인지과학 연구 결과를 기반으로 합니다:

#### 인지과학 연구 기반
- **배들리-히치 모델**: 작업 기억의 음운 고리 이론
- **키스 레이너 연구**: 안구 운동과 인지 처리 과정
- **엘리자베스 쇼터 연구**: 독서 병목 현상 분석

#### 훈련 효과 설명
- **읽기 속도 향상**: 분당 150-250단어 → 500-600단어
- **이해도 개선**: 의미 기반 처리로 깊이 있는 이해
- **집중력 증대**: 시각적 주의 집중으로 효율성 향상

### 실습 가이드
각 훈련 단계별로 구체적인 실습 방법을 제시합니다:

#### 단계별 실습 방법
1. **이론 단계**: 핵심 개념 이해 및 목표 설정
2. **실습 단계**: 구체적인 훈련 방법과 주의사항
3. **읽기 단계**: 선택한 자료로 실제 훈련
4. **이해도 확인**: 객관식 질문을 통한 학습 효과 측정

#### 훈련 팁
- **정확성 우선**: 속도보다 정확한 이해에 집중
- **단계적 향상**: 천천히 시작하여 점진적으로 속도 향상
- **정기적 연습**: 습관화를 위한 지속적인 훈련
- **개인 맞춤**: 개인 수준에 맞는 난이도 선택

## 🎨 UI/UX 특징

### 다크모드 완전 지원
모든 컴포넌트가 라이트/다크 모드를 완전히 지원합니다:

#### 색상 체계
- **라이트 모드**: 밝은 배경에 어두운 텍스트
- **다크 모드**: 어두운 배경에 밝은 텍스트
- **대비 최적화**: WCAG 가이드라인 준수

#### 컴포넌트별 다크모드
- **Alert 컴포넌트**: 경고/안내 메시지
- **Card 컴포넌트**: 읽기 자료 카드
- **Button 컴포넌트**: 모든 버튼 요소
- **Text 요소**: 제목, 설명, 내용 텍스트

### 반응형 디자인
모든 디바이스에서 최적화된 경험을 제공합니다:

#### 화면 크기별 최적화
- **모바일**: 터치 친화적 인터페이스
- **태블릿**: 중간 크기 화면 최적화
- **데스크톱**: 전체 기능 활용 가능

#### 레이아웃 적응
- **그리드 시스템**: 화면 크기에 따른 자동 조정
- **텍스트 크기**: 가독성을 위한 적응형 크기
- **버튼 크기**: 터치/클릭 최적화

### 접근성
모든 사용자가 편리하게 사용할 수 있도록 설계되었습니다:

#### 색상 대비
- **텍스트 대비**: 최소 4.5:1 비율 유지
- **배경 대비**: 명확한 구분을 위한 충분한 대비
- **상태 표시**: 선택/비선택 상태의 명확한 구분

#### 키보드 네비게이션
- **탭 순서**: 논리적인 키보드 이동 순서
- **포커스 표시**: 현재 선택 요소의 명확한 표시
- **단축키**: 자주 사용하는 기능의 키보드 단축키

## 📊 성과 측정

### 실시간 모니터링
훈련 과정에서 실시간으로 성과를 측정합니다:

#### WPM (Words Per Minute)
- **측정 방법**: 읽은 단어 수 / 소요 시간
- **정확도**: 오타 및 수정을 고려한 계산
- **개선 추이**: 세션별 읽기 속도 변화 추적

#### 이해도 점수
- **측정 방법**: 객관식 질문 정답률
- **질문 유형**: 내용 이해, 핵심 개념 파악
- **점수 체계**: 백분율 기반 평가

#### 진행률
- **단계별 완료**: 각 훈련 단계의 완료 상태
- **모듈별 진행**: 전체 모듈 진행 상황
- **전체 진행률**: 전체 훈련 과정의 완료율

### 개인화된 피드백
개인 성과에 따른 맞춤형 피드백을 제공합니다:

#### 성과 분석
- **강점 식별**: 잘하는 영역 파악
- **개선점 발견**: 부족한 영역 분석
- **개선 방향**: 구체적인 개선 방법 제시

#### 학습 경로
- **난이도 조정**: 개인 수준에 맞는 난이도 설정
- **추천 모듈**: 다음 학습할 모듈 추천
- **학습 계획**: 개인별 최적화된 학습 경로

#### 동기부여
- **성과 인정**: 개선된 부분에 대한 긍정적 피드백
- **목표 설정**: 다음 목표 제시
- **지속 동기**: 꾸준한 학습을 위한 동기부여

## 🔧 기술적 구현

### 컴포넌트 구조
모듈화된 컴포넌트 구조로 유지보수성을 높였습니다:

#### 훈련 관련 컴포넌트
```
components/Training/
├── TrainingSession.tsx      # 메인 훈련 세션
├── TrainingHelpModal.tsx    # 도움말 모달
├── ModuleSelector.tsx       # 모듈 선택
├── ReadingSelector.tsx      # 읽기 자료 선택
├── ReadingTraining.tsx      # 읽기 훈련
└── TrainingModal.tsx        # 훈련 모달
```

#### UI 컴포넌트
```
components/ui/
├── alert.tsx               # 알림 컴포넌트
├── button.tsx              # 버튼 컴포넌트
├── card.tsx                # 카드 컴포넌트
├── progress.tsx            # 진행률 컴포넌트
└── tabs.tsx                # 탭 컴포넌트
```

### 상태 관리
React의 useState와 useEffect를 활용한 효율적인 상태 관리:

#### 훈련 상태
- **현재 단계**: 훈련 진행 단계 추적
- **훈련 타입**: 모듈/리딩 훈련 구분
- **선택된 자료**: 선택된 모듈 또는 읽기 자료

#### UI 상태
- **텍스트 크기**: 4단계 텍스트 크기 조절
- **도움말 모달**: 도움말 표시 상태
- **다크모드**: 테마 설정 상태

### 데이터 구조
타입 안전성을 보장하는 TypeScript 기반 데이터 구조:

#### 훈련 모듈 타입
```typescript
interface TrainingModule {
  id: string
  title: string
  description: string
  difficulty: string
  duration: number
  icon: React.ComponentType
  steps: TrainingStep[]
}
```

#### 읽기 자료 타입
```typescript
interface ReadingChapter {
  id: string
  title: string
  content: string
  difficulty: string
  estimatedTime: number
  type: 'fiction' | 'non-fiction'
  source: string
  questions?: Question[]
}
```
